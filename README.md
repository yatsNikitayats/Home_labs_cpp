\# GEMS



\## Описание проекта



Игра GEMS — реализация механики match-3 на C++ с использованием SFML.



Игровое поле состоит из цветных квадратов.

Игрок может менять местами две соседние клетки.



Если после обмена образуется группа из 3 или более соседних клеток одного цвета, клетки уничтожаются.



После удаления:

\- оставшиеся клетки падают вниз

\- выполняется повторная проверка поля

\- возможны каскадные реакции



\## Бонусы



При уничтожении клеток может появиться случайный бонус

в радиусе 3 клеток от места удаления.



\### 1. COLORIZE



Перекрашивает:

\- клетку с бонусом

\- две случайные НЕсоседние клетки

в радиусе 3



в цвет исходной клетки.



\### 2. BOMB



Уничтожает:

\- 5 случайных клеток поля

\- включая клетку с бонусом

\# Структура проекта



\## Game.h / Game.cpp



Главный игровой класс.



Отвечает за:

\- создание окна,

\- игровой цикл,

\- обработку ввода,



\---



\## Board.h / Board.cpp



Класс игрового поля.



Хранит:

\- клетки,

\- бонусы,

\- размеры поля.



Реализует:

\- swap клеток,

\- get/set операции,

\- очистку бонусов,

\- проверку пустых клеток.





\## BoardInitializer.h / BoardInitializer.cpp



Начальная генерация поля.



Отвечает за:

\- случайную генерацию поля,

\- отсутствие стартовых комбинаций.



\## BoardMatchFinder.h / BoardMatchFinder.cpp



Поиск комбинаций на поле.



Реализует:

\- DFS обход,

\- поиск связных компонент,

\- определение групп из 3+ клеток.





\## BoardGravity.h / BoardGravity.cpp



Механика гравитации.



Отвечает только за:

\- падение клеток вниз,

\- перемещение бонусов вместе с клетками,

\- очистку пустых ячеек.





\## BoardResolver.h / BoardResolver.cpp



логика обработки поля.



Отвечает за:

\- поиск комбинаций,

\- удаление клеток,

\- создание бонусов,

\- дозаполнение поля.



\## Bonus.h



Описание бонусов и эффектов.





\## BonusManager.h / BonusManager.cpp



Система бонусов.



Реализует:

\- создание бонусов,

\- проверку допустимых позиций,

\- активацию бонусов,

\- механику бонусов.



\## Utils.h / Utils.cpp



Вспомогательные функции.



Содержит:

\- генератор случайных чисел,

\- проверку границ,

\- Manhattan distance,

\- выбор цвета клетки.





\# Бонусы



\## Colorize Bonus



Перекрашивает:

\- клетку попадания,

\- две случайные несоседние клетки

в цвет исходной клетки.



\## Bomb Bonus



Уничтожает:

\- клетку попадания,

\- еще 4 случайные клетки поля.

\# Как запустить проект



\## 1. Скачать SFML



Скачать:

https://www.sfml-dev.org/download/sfml/3.0.0/



Версия:

\- Visual C++ 17 (2022)

\- 64-bit



Распаковать архив.



Например:



C:\\SFML



\---



\# Настройка Visual Studio



\## 1. Создать проект



Visual Studio:



Create new project



&#x20;Console App (C++)



\---



\## 2. Включить C++20



Project

&#x20;Properties

&#x20;C/C++

&#x20;Language

&#x20;C++ Language Standard



Выбрать:



ISO C++20 Standard



\---



\## 3. Подключить include



Project

&#x20;Properties

&#x20;C/C++

&#x20;General

&#x20;Additional Include Directories



Добавить:



C:\\SFML\\include



\---



\## 4. Подключить lib



Project

&#x20;Properties

&#x20;Linker

&#x20;General

&#x20;Additional Library Directories



Добавить:



C:\\SFML\\lib



\## 5. Подключить библиотеки



Project

&#x20;Properties

&#x20;Linker

&#x20;Input

&#x20;Additional Dependencies



Для Debug:



sfml-graphics-d.lib

sfml-window-d.lib

sfml-system-d.lib





\## 6. DLL файлы



Из папки:



C:\\SFML\\bin



скопировать рядом с:



project.exe



Для Debug нужны:



sfml-graphics-d-3.dll

sfml-window-d-3.dll

sfml-system-d-3.dll
