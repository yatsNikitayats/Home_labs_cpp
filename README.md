# Лаб №2. Моделирование принятия зачета по математике## Условие задачиИмеются задачи – квадратные уравнения, записанные во входном файле. Студенты решают их и отсылают ответы преподавателю. Преподаватель имеет очередь писем на проверку в формате «квадратное ур-ие + решение + имя студента». Студенты бывают:- **хорошие** – они всегда решают задачи правильно- **средние** – у них есть вероятность решить задачу правильно, но они могут и ошибаться- **плохие** – они всегда пишут, что корень один и это 0Преподаватель может проверить все письма из очереди по наступлению зачетной недели и записывать в таблицу имя студента и кол-во успешно решенных задач. Преподаватель может опубликовать таблицу успеваемости.---## ПрограммаПрограмма для моделирования процесса проверки студенческих работ по решению квадратных уравнений.### Описание работыПрограмма имитирует реальный процесс:1. Читает квадратные уравнения из файла `equations.txt`2. Раздает задачи студентам разных уровней подготовки3. Студенты решают уравнения 4. Преподаватель проверяет ответы5. Выводит итоговую таблицу успеваемости## Типы студентов**GOOD - Всегда решает правильно **MID - 50% вероятность правильного решения **BAD - Всегда отвечает, что корень один и это 0 ## Формат входного файлаФайл `equations.txt` содержит коэффициенты квадратных уравнений в формате:Результат: Загружено уравнений: 15Сгенерировано писем: 75Проверено писем: 75 Итоги зачетной неделиХаймин              | 2Куликова            | 8Фролов              | 14Славгородский       | 5Яцишин              | 14
